## Owner-account activation
1. In Google Search Console, add the Domain property juplifestudio.com. Copy its actual DNS TXT verification token into Cloudflare DNS. After verification submit https://juplifestudio.com/sitemap.xml, then inspect/request indexing for the homepage and four collection pages. Alternatively use a URL-prefix property with the actual HTML verification token. Never publish a placeholder token.
2. Add the site to Bing Webmaster Tools (import the verified Search Console property if available), submit the same sitemap, inspect crawl/index reports. IndexNow is optional; it requires a real generated key and endpoint verification, not a pretend submission.
3. Google Business Profile requires eligible in-person customer contact. An online-only studio is not eligible. Confirm whether Dee serves customers in person before creating a profile. If eligible, verify with the actual business details and keep a residential address hidden when appropriate. Do not claim a showroom, pickup hours or service area not confirmed.
4. Make the name, website, phone and email consistent across X and any real social/business profiles. Add further sameAs links only once the exact profiles are verified.
5. Merchant Center/product offers: wait for released products, actual prices, stock/lead times, final photographs and approved shipping/returns. Then add Product/Offer structured data, validate in Rich Results Test, and publish a matching product feed.

Separate inquiries from purchases. Do not invent a current baseline. If analytics is desired, select the owner’s account and privacy approach before adding tracking.
